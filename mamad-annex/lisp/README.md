# migun.lsp — כלי נספחי המיגון לאוטוקאד

## התקנה (פעם אחת)
1. שמור את `migun.lsp` בתיקייה קבועה (למשל `C:\migun\`).
2. פתח את `migun-lib.dxf` באוטוקאד ושמור אותו כ-`migun-lib.dwg` באותה תיקייה
   (הקובץ נבנה מספריית הבלוקים של המשרד — פרטי פתחים, חתכים, סימוני זיון).
3. באוטוקאד: `APPLOAD` → בחר את `migun.lsp` → Load.
   כדי שייטען אוטומטית בכל פתיחה: הוסף אותו ל-Startup Suite באותו חלון.

## עבודה שוטפת
| פקודה | מה היא עושה |
|---|---|
| `MMD` | סימון מרחב מוגן בתוכנית האדריכלית: 3 קליקים לפינות, קליק לכל עובי קיר, ואז דלת/חלון/צינור בקליקים. הנתונים נשמרים בתוך ה-DWG. |
| `MMDDRAW` | מייצר את הנספח: תוכנית לכל מרחב עם קירות/פתחים/הצללה/מידות, חתך לכל מרחב, טבלה מרכזת והערות כלליות. |
| `MMDDETAILS` | מזריק את פרטי הפתחים של המשרד (פרט פתח חלון / פרט פתח דלת) לכל פתח שנאסף. |
| `MMDLIB` | טוען את ספריית הבלוקים לשרטוט הנוכחי (נדרש פעם אחת לכל DWG). |
| `MMDLIST` / `MMDDEL` / `MMDCLR` | רשימה / מחיקה / ניקוי. |

בזמן האיסוף הכלי מדפיס התראות `!!` כשמשהו חורג מכללי פקע"ר
(רוחב דלת לא תקני, צינור קרוב מדי לפתח, גובה צינור נמוך מדי...).
ההתראות לא חוסמות — אתה המחליט.

## הנחות
- השרטוט בס"מ (`*MG-UNITS*` בראש הקובץ — לשינוי אם עובדים במטרים).
- הפקודות עובדות גם על תוכנית מסובבת — הכיוון נקבע בקליק השני.
- `migun.lsp` נבנה מ-`migun.lsp.src` (UTF-8) עם `python3 build_lsp.py`.
  אין לערוך את migun.lsp ישירות — עורכים את ה-src ובונים מחדש.

## למה ככה
- כל הגאומטריה ב-`entmake` — לא מושפע מ-OSNAP/ORTHO/Dynamic Input.
- עברית לישויות נכתבת כ-`\U+XXXX` (חסין קידוד); הודעות מסך ב-cp1255.
- משתני מערכת נשמרים ומוחזרים, כולל בביטול באמצע (`*error*` handler).
