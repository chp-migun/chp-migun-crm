# מחולל נספחי מיגון — מסמך פרויקט

מטרה: כלי עבודה קבוע לאוטוקאד עבור יועץ מיגון, שמייצר נספחי ממ"דים
(תוכניות + חתכים), ובהמשך פרטי ריתום/חלון/דלת פרמטריים ונספח קונסטרוקציה.

## החלטות שהתקבלו (26.08.2026)

| נושא | החלטה |
|---|---|
| סביבת עבודה | AutoCAD מלא (לא LT) — AutoLISP |
| נקודת מוצא | DWG אדריכלי 1:100 שמגיע מהאדריכל (תוכניות, חתכים, חזיתות) |
| קלט מידות | **סימון בשרטוט האדריכלי** — הכלי מודד לבד, לא מקלידים |
| היקף נספח | כל הממ"דים בבניין בנספח אחד |
| תוצר ראשון | נספח ממ"דים + חתכים (שם נשרף הכי הרבה זמן) |
| תוצר שני | פרטי ריתום/פתחים — אותו פרט עם שינוי מידות וזיון ⇒ פרמטריזציה משתלמת |
| מקור כללים | המשתמש מעלה מסמכים + נספח לדוגמה; הכללים מחולצים משם ומאושרים על ידו |

## ארכיטקטורה מתוכננת

1. **MIGUN-PICK** (LISP אינטראקטיבי) — מסמנים ממ"ד בתוכנית האדריכלית:
   פינות פנים / קווי קירות / פתחים. הכלי מודד, מזהה עוביים, מריץ בדיקות
   מול הכללים, ושומר את הממ"ד ברשימת הבניין. חוזרים לכל ממ"ד.
2. **MIGUN-SHEET** — פורס גיליון שלם: תוכנית לכל טיפוס ממ"ד, חתכים,
   טבלה מרכזת של כל הממ"דים, מקרא, הערות, מסגרת ושדה כותרת.
3. **MIGUN-DETAIL** (שלב ב') — ספריית פרטים פרמטרית: פרט ריתום, פרט
   חלון הדף, פרט דלת הדף. קלט: עובי קיר, מידות פתח, זיון.
4. **דף HTML** (`index.html`) — עורך כללים והגדרות + תצוגה מקדימה;
   מייצר/מעדכן את קובץ ה-LISP. הגרסה הנוכחית (טופס ידני) היא שלד
   הוכחת-היתכנות בלבד וצפויה להשתנות.

## עקרונות טכניים (נבדקו ועובדים בשלד)

- כל הגאומטריה ב-`entmake`, לא `command` — חסין ל-OSNAP/ORTHO/Dynamic Input.
- עברית בקבצי ‎.lsp‎ נכתבת כ-`\U+XXXX` (הקובץ נקרא ANSI, לא UTF-8).
- שמות שכבות ASCII עם קידומת מוגדרת (ברירת מחדל `MIGUN-`).
- זוויות ב-entmake ברדיאנים.
- שמירה/שחזור מלא של משתני מערכת + ‎*error*‎ handler.
- מודל גאומטריה אחד משותף לתצוגה המקדימה (SVG) ולפלט ה-LISP.
